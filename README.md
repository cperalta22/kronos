## 📖 Descripción del Proyecto

Este repositorio contiene la adaptación lúdica y académica del mito de **Cronos (Κρόνος)**, basada en la *Teogonía* de Hesíodo y programada para la consola de fantasía **PICO-8**. 

En esta reinterpretación, el jugador encarna a Cronos recorriendo el laberinto de las edades cósmicas y devorando las simientes del tiempo antes de que la profecía de su destronamiento se cumpla.

---

## 🎮 Cómo Jugar
1. **En línea:** Publicado a través de **GitHub Pages** (en la pestaña *Settings > Pages* de este repositorio).
2. **Localmente:** Abre el archivo `index.html` en cualquier navegador web.

### Controles:
* **Moverse:** Flechas de dirección (<kbd>←</kbd> <kbd>↑</kbd> <kbd>→</kbd> <kbd>↓</kbd>)
* **Acción / Inicio:** Tecla <kbd>Z</kbd> o <kbd>C</kbd> (Botón O)
* **Secundario:** Tecla <kbd>X</kbd> o <kbd>V</kbd> (Botón X)

## ✏️ Cómo editar la información (Para Cristóbal)

Para que Cristóbal pueda actualizar sus datos (materia, carrera, introducción, instrucciones) directamente desde la web de GitHub sin tocar código HTML ni CSS:

1. Entra a la carpeta [`contenido/datos.js`](contenido/datos.js).
2. Haz clic en el ícono del **lápiz ✏️** (*Edit this file*) en la parte superior derecha.
3. Modifica los campos deseados (están claramente señalados y comentados).
4. Haz clic abajo en el botón verde **"Commit changes..."**.
5. ¡Los cambios se reflejarán automáticamente en la página web!

Para más detalles, consulta la [Guía de edición paso a paso](contenido/README_EDITAR.md).
