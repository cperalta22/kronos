# 🏛️ Guía para Cristóbal: Cómo editar los textos de tu proyecto

¡Hola Cristóbal! Modificar los textos de la página web (materia, carrera, introducción mitológica, instrucciones) es muy sencillo y puedes hacerlo directamente desde el navegador en GitHub sin necesidad de instalar nada:

### Pasos para editar:
1. Entra a la carpeta `contenido/` en este repositorio de GitHub.
2. Abre el archivo **`datos.js`**.
3. Haz clic en el ícono del **lápiz ✏️** ("Edit this file") ubicado en la esquina superior derecha del archivo.
4. Modifica los textos que desees:
   - **`materia`**: Escribe el nombre exacto de la materia de tu tarea.
   - **`carrera`**: Tu carrera o licenciatura (o déjalo en blanco si prefieres).
   - **`introduccion`**: Puedes cambiar o complementar la introducción sobre el mito de Cronos.
   - **`instrucciones`**: Puedes añadir o ajustar consejos de juego.
   *(Ten cuidado de mantener las comillas ` y comas que rodean los textos).*
5. Cuando termines, haz clic en el botón verde **"Commit changes..."** (Guardar cambios) en la parte superior derecha.
6. ¡Listo! Los cambios se verán reflejados de inmediato en la página web.
